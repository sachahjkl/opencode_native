opencode native

A native desktop client for the opencode server. One program for Windows or Linux, no runtime to install, every session and sub-agent streamed live.

Download the latest release Source on GitHub

Windows 10 / 11 x64  ·  Linux x64 (Vulkan)  ·  MIT

Streamed live

Sessions grouped by project, the conversation from the server's event stream: Markdown with real tables, code with a copy button, reasoning, every tool call with its input and output, tokens and cost. Scroll up as far as the session goes: earlier messages come by themselves, and the keyboard scrolls too.

Sub-agents in front

A card per launch with its state, live activity, model and cost; the running ones lit and counted; drill down into any of them and come back with Alt+Left.

Search as you type

Ctrl+F lights every match in the conversation and scrolls to the next. The agent and model pickers match subsequences ("cs5" finds Claude Sonnet 5) and light the letters that matched.

Several servers

The opencode desktop app's server is found by itself; add others (an address, a password) and switch from the status bar.

Statistics

Click the token count: totals, the context window filled, time and pace, tools with their failures, models, sub-agents, and the whole project's numbers.

Machined, and quiet

opencode's dark palette with bevelled buttons, sunken wells and carved grooves; lamps only where something is live. Resizing never stretches a frame, and a key reaches the screen in about 34 ms.

Download

Windows

One executable (Windows 10 and 11, x64). Run it, or install it for your user from its Setup (title bar menu): a Start menu shortcut and a Settings > Apps entry, no administrator rights.

opencode-native-<version>-windows-x64.exe

Linux

One program in an archive (x64). Run it, or ./opencode-native --install for an entry in the applications menu. Needs Vulkan, libxkbcommon, fontconfig, Wayland or X11.

opencode-native-<version>-linux-x64.tar.gz
