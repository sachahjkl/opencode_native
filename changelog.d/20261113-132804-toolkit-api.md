type: Changed

**Messages follow the Messages setting, dialogs sit in the middle**: every message (a copy, a failure, an update ready) now goes where Settings › General › Messages says: a system notification, a message in the window, or none (a failure is always shown). A message you can click (an update to install, a session to open) stays in the window.
  - The dialogs are centred in the window: the pairing dialog and the image viewer's wait sat higher.
  - The application menu, the server menu and the sub-agents menu filter their items as you type.
  - The size you give a dialog is now kept in text units: a dialog you resized before opens as large as the window once; resize it again.
